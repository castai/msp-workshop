## Locust

- **Project:** https://github.com/locustio/locust
- **Image registry:** Docker Hub (`docker.io/locustio/locust`)
- **Image reference:** `locustio/locust:2.32.2`
- **Docker Hub tag page:** https://hub.docker.com/v2/repositories/locustio/locust/tags/2.32.2/

### Why `2.32.2`

- Official upstream image maintained by the Locust project — published under `locustio/locust`
  on Docker Hub, with source tags tied to GitHub releases.
- Pinned semver tag (not `latest` / `master`), so behavior is reproducible across cluster
  recreations.
- Well-tested stable release line; matches the Locust 2.x server / worker protocol we expect
  the workshop's Helm chart to target (avoids surprise protocol changes introduced in newer
  majors).
- Verified present on Docker Hub with a published `last_updated` of 2024-11-08.
